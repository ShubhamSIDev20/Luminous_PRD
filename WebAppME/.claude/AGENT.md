## Project Overview
BatteryTestingSystem is an ASP.NET Core 8 application for managing battery testing hardware: devices, secondary boards, channels, test programs, and battery sessions. It combines a Blazor Server UI, a REST API, an MCP server for tool-based device control, and background export jobs.

**Stack:** C# / .NET 8 (`Microsoft.NET.Sdk.Web`) | ASP.NET Core 8 (Blazor Server + MVC Controllers) | EF Core 8 + SQLite (optional SQLCipher) | Hangfire (background jobs) | Serilog (logging) | MCP (ASP.NET Core MCP server)

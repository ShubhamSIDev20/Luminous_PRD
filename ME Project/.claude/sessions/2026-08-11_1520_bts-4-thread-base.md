## 🔍 Discoveries This Session

1. **Both UDP sockets have been open since day one with no destination.**
   `udp_sock.c` created and bound them; nothing ever built a `sockaddr_in` to
   send *to*. Invisible while nothing was sent, and the first thing that would
   have failed on the demo. Fixed in `sys_init.c`.
2. **`NULL` was reaching `proto/` transitively through MinGW's headers.** The
   host build passed; the ARM cross-build failed. Four `proto/` headers now
   include `<stddef.h>` explicitly. A reminder that a green native build says
   nothing about the target (ADR-3).
3. **`me_config_t` was already taken** by `sys_init.h` for the CLI config. The
   per-circuit stored configuration is `me_circuit_config_t`.
4. **`.bss` is 261 MB (`NOBITS`), binary still 4.1 MB.** Confirms the
   demand-zero reasoning — but Docker limits count RSS, so this needs a
   `docker stats` check on hardware (T-27).
